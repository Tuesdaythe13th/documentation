The ARTIFEX Labs notebook suite is a collection of self-contained Google Colab notebooks, each implementing a distinct evaluation pipeline within the ARTIFEX v7–v10 multilingual compositional safety evaluation framework. You can open any notebook directly in your browser, run the full pipeline without any local setup, and inspect every decision through structured audit logs. The notebooks span multilingual safety benchmarking, dialect divergence analysis, agentic alignment evaluation, cohort fairness analysis, and pedagogical design guides — all grounded in the 2026 Measurement Science framework and aligned to NIST AI 800-3, ISO/IEC 42119, and MLCommons AILuminate standards.

## How to Open and Run Any Notebook

<Steps>
  <Step title="Click 'Open in Colab'">
    Find the notebook you want in the table below and click its Colab link or badge. This opens the notebook directly in Google Colab — no cloning or local install required.
  </Step>
  <Step title="Start the runtime">
    In Colab, select **Runtime → Run all** to execute every cell in sequence. You can also step through cells individually if you want to inspect intermediate outputs.
  </Step>
  <Step title="Add API keys via Secrets">
    If a notebook calls an external LLM (OpenAI, Anthropic), you will be prompted to supply your API key. Add it through the Colab **Secrets** panel (the key icon in the left sidebar) using the variable name shown in the notebook — typically `OPENAI_API_KEY` or `ANTHROPIC_API_KEY`. The notebooks never hard-code credentials.
  </Step>
  <Step title="Inspect outputs">
    Each notebook writes structured outputs — CSV files, JSON manifests, visualizations — into the Colab working directory. The final cell dumps the full `RUBRIC_LOG` audit trail so you can verify every pipeline decision.
  </Step>
</Steps>

<Note>
  Every notebook in the suite includes a **§ 2026 Measurement Science** cell that maps the notebook's methodology to NIST AI 800-3 Generalized Linear Mixed Models (GLMMs), IRT 3PL item-level diagnostics, and all five facets of validity (content, construct, criterion, external, consequential). This cell runs automatically and appends its output to the audit log.
</Note>

## Prerequisites

<CardGroup cols={2}>
  <Card title="Google Account" icon="google">
    A free Google account is all you need to open and run any notebook in Google Colab. No local Python environment or GPU is required.
  </Card>
  <Card title="API Keys (Optional)" icon="key">
    OpenAI or Anthropic API keys unlock LLM-as-Judge and summarization features. Without keys, notebooks fall back to extractive summarization and the offline `StubEncoder`. Add keys via Colab Secrets — never paste them into cells.
  </Card>
</CardGroup>
